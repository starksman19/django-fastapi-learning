# Port Appointments — Django

Przestrzeń na samodzielne odtworzenie kontraktu Appointments przy użyciu
Django, Django REST Framework, Django ORM i osobnej bazy PostgreSQL.

Implementacja może różnić się architekturą od wersji FastAPI, lecz musi
zachować ten sam kontrakt HTTP, reguły stref czasowych, idempotencję, przejścia
stanów i ochronę przed podwójną rezerwacją.

Nie ma tu gotowej implementacji — jest to celowe miejsce do nauki.
