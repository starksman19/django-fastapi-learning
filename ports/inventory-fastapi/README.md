# Port Inventory & Orders — FastAPI

Przestrzeń na samodzielne odtworzenie kontraktu Inventory & Orders przy użyciu
FastAPI, SQLAlchemy, Alembic i osobnej bazy PostgreSQL.

Implementacja może różnić się architekturą od wersji Django, lecz musi zachować
te same ścieżki, statusy, payloady, błędy, skutki w bazie, reguły idempotencji i
zachowanie podczas współbieżnych żądań.

Nie ma tu gotowej implementacji — jest to celowe miejsce do nauki.
