# Samodzielne porty

Ten katalog jest przeznaczony na implementacje tworzone samodzielnie w drugim
stosie technologicznym. Porty mają korzystać z dokumentacji kontraktu i
wspólnych testów, a nie zawierać skopiowanego rozwiązania referencyjnego.

Planowane aplikacje:

- `inventory-fastapi/` — port Inventory & Orders do FastAPI;
- `appointments-django/` — port Appointments do Django REST Framework.

Na obecnym etapie znajdują się tu tylko instrukcje i placeholdery.
