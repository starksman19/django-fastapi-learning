# Infrastruktura

Ten katalog będzie przeznaczony na Dockerfile, Docker Compose, konfigurację
czterech odizolowanych baz PostgreSQL, migracje startowe, healthchecki oraz
uruchamianie testów kontraktowych.

Przygotowanie infrastruktury jest osobnym ćwiczeniem edukacyjnym. Dlatego na
tym etapie nie ma tu gotowych obrazów ani pliku `docker-compose.yml`.
