# Referencyjne Inventory & Orders — Django

Miejsce na kompletną implementację Inventory & Orders API w Django, Django
REST Framework i Django ORM, korzystającą z własnej bazy PostgreSQL.

W przyszłości katalog będzie zawierał konfigurację aplikacji, modele, migracje,
endpointy, testy i healthcheck. Szczególny nacisk zostanie położony na atomową
rezerwację zapasu, blokady wierszy i ochronę przed oversellingiem.
