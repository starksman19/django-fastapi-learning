# Referencyjne Appointments — FastAPI

Miejsce na kompletną implementację Appointments API w FastAPI, SQLAlchemy i
Alembic, korzystającą z własnej bazy PostgreSQL.

W przyszłości katalog będzie zawierał konfigurację aplikacji, modele, migracje,
endpointy, testy i healthcheck. Najważniejszym scenariuszem będzie bezpieczna
obsługa równoległych prób rezerwacji tego samego terminu.

Obecnie jest to wyłącznie placeholder dokumentacyjny.
