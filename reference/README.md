# Implementacje referencyjne

Ten katalog jest przeznaczony na kompletne, działające przykłady przygotowane
jako punkt odniesienia dla samodzielnych portów. Implementacje referencyjne
definiują zachowanie, ale wspólnym źródłem prawdy pozostają opisany kontrakt
HTTP i testy kontraktowe.

Planowane aplikacje:

- `inventory-django/` — Inventory & Orders w Django REST Framework;
- `appointments-fastapi/` — Appointments w FastAPI i SQLAlchemy.

Na obecnym etapie nie ma tu kodu aplikacji.
