# Scenariusze kontraktowe Inventory & Orders

Miejsce na scenariusze uruchamiane przeciwko `reference/inventory-django` i
`ports/inventory-fastapi`. Najważniejsze przypadki obejmą zakup ostatniej
sztuki przez dwóch klientów, idempotentne tworzenie zamówienia, anulowanie i
zwolnienie rezerwacji oraz rollback po błędzie.

Obecnie katalog nie zawiera wykonywalnych testów.
