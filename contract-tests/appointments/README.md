# Scenariusze kontraktowe Appointments

Miejsce na scenariusze uruchamiane przeciwko `reference/appointments-fastapi`
i `ports/appointments-django`. Najważniejsze przypadki obejmą równoległe próby
rezerwacji jednego terminu, wykrywanie nakładania wizyt, idempotencję i
niedozwolone przejścia stanów.

Obecnie katalog nie zawiera wykonywalnych testów.
