# Dane testowe

Miejsce na współdzielone, deterministyczne dane i fabryki potrzebne testom
kontraktowym. Te same znaczeniowo dane będą przygotowywane niezależnie w bazie
implementacji referencyjnej i portu.

Nie należy umieszczać tu sekretów, prawdziwych danych osobowych ani danych
dostępowych. Obecnie katalog jest placeholderem.
