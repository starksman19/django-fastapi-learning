# Testy kontraktowe

Ten katalog docelowo będzie zawierał wspólne testy czarnoskrzynkowe wykonywane
po HTTP przeciwko implementacji referencyjnej i odpowiadającemu jej portowi.

Testy będą sprawdzać kontrakt żądań i odpowiedzi, walidację, błędy, skutki w
bazie, idempotencję, maszyny stanów oraz zachowanie przy równoległych
żądaniach. Dynamiczne identyfikatory i znaczniki czasu będą normalizowane albo
porównywane semantycznie.

Na obecnym etapie nie dodano frameworka testowego ani scenariuszy wykonywalnych.
