# Kontrakty API

Miejsce na wersjonowany opis kontraktów Inventory & Orders oraz Appointments:
ścieżek, metod, parametrów, nagłówków, payloadów, statusów HTTP, błędów,
walidacji, idempotencji i maszyn stanów.

Kontrakt będzie wspólny dla implementacji referencyjnej i portu. Jego zmiana
powinna pociągać za sobą aktualizację dokumentacji, testów kontraktowych oraz
obu implementacji danej domeny.

Obecnie konkretne endpointy nie są jeszcze zdefiniowane.
